# Phishing URL Scanner

## Overview
This project is a Python-based phishing URL detection tool developed as part of my Master's Cybersecurity Capstone project at DePaul University.

The tool analyzes URLs and identifies phishing indicators using domain validation, WHOIS information, and security-focused risk assessment techniques.

## Features

- URL analysis
- Domain validation
- WHOIS lookup
- Phishing risk assessment
- Security-focused URL inspection

## Technologies Used

- Python
- WHOIS
- Linux
- Cybersecurity Analysis

app.py - Main application
